# Repo Visual Docs

A local, repo-backed visual documentation workspace for code review and agent handoff.

This workspace is repo-native: the MDX files are local source files, comments stay beside them in `comments.json`, and the Plan UI reads them through the localhost bridge instead of writing the plan to hosted storage.

Manifest: `../../../agent-native.json`

## Architecture at a glance

Mesa is a Next.js application deployed on Vercel. Supabase Auth authenticates household members; Next.js route handlers enforce application authorization and call Supabase using the user's session. Recipes, profiles, products, plans and shopping state are stored in one revisioned JSONB workspace per household. PDF originals are kept in a private Storage bucket. The optimizer runs in an isolated Node worker and uses HiGHS to solve a mixed integer linear program. Mercadona is an external, unofficial catalog integration behind an adapter.

## Review And Agent Handoff

Comment on sections, diagrams, specs, or wireframes in the local Plan UI. Agent-targeted comments are the queue for a coding agent to update the repo and then patch these MDX files so the visual docs stay current with code.
